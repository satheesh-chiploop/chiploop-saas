The required synthesizable top module is motor_control_top. Do not substitute a status, telemetry, register-bank, or leaf module as the design top. The top must retain the motor-control request/response, safety, timeout, and actuator-command behavior.
Design a synthesizable ASIC RTL block named doMINO_aeroguard_ctrl. The block shall implement safety-gated transport and actuator-command handling for an external NVIDIA DoMINO automotive-aero service. The RTL shall not implement the physics surrogate, CFD, mesh generation, or any tensor inference. The RTL shall contain: (1) a control/status register file; (2) a request packer; (3) a response unpacker; (4) a freshness/timeout safety monitor; (5) a command shaper with clamping; (6) a fault manager; and (7) a top-level transaction controller.

Clocking/reset: single clk and active-low rst_n. All state shall reset deterministically. No asynchronous data paths are required. Use synchronous logic for state, counters, flags, and output registers.

Top-level interfaces: expose one 32-bit register window for configuration and status, one bounded valid/ready request stream no wider than 128 bits, one bounded valid/ready response stream no wider than 128 bits, and one 32-bit actuator command output with command_valid. Do not expose geometry arrays, flow fields, surface-pressure grids, or any surrogate-model payload as individual pins. Do not use more than 128 bits on any streaming bus. Keep scalar-equivalent I/O below 256.

Control register file: implement programmable fields for control_enable, stream_timeout_cycles, min_actuator_cmd, max_actuator_cmd, safe_fallback_cmd, expected_seq, model_ready status, fault_latched, last_seq_seen, and last_error_code. These may be implemented as flops or small decode logic. Bulk payload storage is not permitted in the RTL. If any future payload store is required for ASIC implementation, it must use the Sky130 hard macro sky130_sram_1kbyte_1rw1r_32x256_8 only, with ports clk0, csb0, web0, wmask0[3:0], addr0[7:0], din0[31:0], and dout0[31:0]. Multiple instances may be banked only if capacity is required. Do not infer SRAM with reg arrays or generic memory. Before any ASIC payload memory instantiation, require complete behavioral Verilog, Liberty, LEF, GDS, and SPICE collateral for the macro. If collateral is incomplete, terminate the design at the memory-collateral gate and do not silently map storage into standard-cell registers.

Request packing: on acceptance of a host request, package a compact 128-bit packet containing protocol version, command type, sequence number, geometry descriptor handle or identifier, flow-condition fields relevant to stream_velocity_mps, and a small integrity check such as parity, CRC, or checksum. Geometry shall be referenced by descriptor/handle derived from the DrivAerML reference geometry in STL form; the RTL shall not parse or expand full STL geometry. The request packer shall assert req_valid only when control_enable is set and the safety monitor permits transaction launch. req_ready shall be sampled for handshake completion. On rejection or timeout, no packet launch shall occur.

Response unpacking: accept a compact 128-bit response packet from the external service. Decode status, sequence number, validity markers, and a command-relevant summary field. The RTL may consume only force-summary or control-intent data needed for actuator command generation. Full drag-force, lift-force, surface-pressure, and flow-field outputs are external model concepts and shall not be expanded into internal compute datapaths. If the response header is invalid, sequence mismatch occurs, or integrity check fails, the response shall be rejected and fault handling shall be triggered.

Freshness and timeout: implement a monotonic sequence check and a programmable timeout counter. A response older than expected_seq, or any response arriving after stream_timeout_cycles, shall be marked stale and rejected. Stale model commands shall not reach actuator outputs. The safety monitor shall assert safe_fallback_active and update fault_code on stale, malformed, disabled, or timed-out transactions.

Command shaping: the actuator_command_shaper shall generate a 32-bit actuator_cmd, but the effective command semantics may be narrower if the application uses only a subset of bits. The block shall clamp the command to the programmable min_actuator_cmd and max_actuator_cmd values before asserting actuator_cmd_valid. If the command is invalid, unavailable, or outside bounds, the shaper shall output safe_fallback_cmd instead. Prefer holding the last known safe command only if it remains within bounds and the system is not fault-latched; otherwise drive the safe fallback command.

Fault management: latch fault conditions until cleared by software. Fault causes shall include stale response, timeout, malformed packet, model-disabled, out-of-envelope request, invalid sequence, and command-clamp event if required by implementation policy. Expose a compact fault_code and fault_latched status in the register file. safe_fallback_active shall be asserted whenever a fault forces fallback behavior or the controller is not permitted to issue model-derived actuation.

Envelope validation: the implementation shall support the declared operating envelope of stream_velocity_mps from 20 to 55. The configured reference condition of 38.89 m/s shall be representable in the request packet. Out-of-envelope values shall not be forwarded as valid model commands and shall cause safe fallback or request rejection.

Transaction policy: only one outstanding request-response transaction needs to be tracked unless the implementation chooses a small bounded outstanding counter. Do not implement large queues. Any buffering beyond small control state is out of scope and prohibited unless a later memory-collateral-approved macro-based design is introduced.

Synthesis and coding style: use synthesizable RTL only. All state machines shall have defined reset states and legal default transitions. No DPI, no behavioral model of DoMINO, no GPU bindings inside RTL, and no unsynthesizable constructs. Keep combinational depth modest and ensure the top-level controller can be implemented in standard-cell ASIC flow.
ASIC MEMORY CONTRACT (mandatory): instantiate sky130_sram_1kbyte_1rw1r_32x256_8 for bulk payload/history/FIFO storage using clk0, csb0, web0, wmask0[3:0], addr0[7:0], din0[31:0], and dout0[31:0]. Do not expand payload, history, FIFO, or telemetry storage into individually named registers, flip-flop arrays, or inferred memories. Small control/status registers are allowed.
