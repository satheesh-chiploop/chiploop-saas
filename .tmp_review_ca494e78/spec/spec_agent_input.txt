Design a smart sensor hub microcontroller subsystem with a memory-mapped register interface.

This IoT edge-node demo should model a small microcontroller-style subsystem around sensor telemetry, local threshold policy, FIFO buffering, interrupt generation, and low-power sampling control. The CPU core may be represented as a firmware-facing control sequencer and register fabric for this reference journey; focus the generated RTL on the sensor hub peripherals and software-visible behavior.

Top module:
- smart_sensor_hub_mcu

Inputs:
- clk
- reset_n
- wr_en
- wr_addr[11:0]
- wr_data[31:0]
- rd_en
- rd_addr[11:0]
- sensor_temp_raw[15:0]
- sensor_humidity_raw[15:0]
- sensor_air_raw[15:0]
- sensor_valid

Outputs:
- rd_data[31:0]
- sensor_sample_req
- alert_irq
- fifo_level[5:0]
- low_power_active
- sample_count[31:0]
- alert_status[7:0]

Register map:
- 0x000 CONTROL: bit 0 ENABLE, bit 1 SAMPLE_START, bit 2 LOW_POWER_EN, bit 3 IRQ_ENABLE, bit 4 FIFO_CLEAR
- 0x004 STATUS: busy, sample_done, fifo_empty, fifo_full, alert_pending, low_power_active
- 0x008 SAMPLE_PERIOD: sample period in controller clock ticks[31:0]
- 0x00C SENSOR_SELECT: enable bits for temperature, humidity, and air-quality channels
- 0x010 TEMP_THRESHOLD: high temperature alert threshold[15:0]
- 0x014 HUMIDITY_THRESHOLD: high humidity alert threshold[15:0]
- 0x018 AIR_THRESHOLD: high air-quality alert threshold[15:0]
- 0x01C LATEST_TEMP: latest sampled temperature[15:0]
- 0x020 LATEST_HUMIDITY: latest sampled humidity[15:0]
- 0x024 LATEST_AIR: latest sampled air-quality value[15:0]
- 0x028 FIFO_DATA: packed sensor sample data, read pops FIFO
- 0x02C FIFO_LEVEL: current FIFO occupancy[5:0]
- 0x030 ALERT_STATUS: temp_alert, humidity_alert, air_alert, fifo_overflow, sample_timeout
- 0x034 ALERT_CLEAR: write one to clear alert bits
- 0x038 SAMPLE_COUNT: completed sample count[31:0]

Functional requirements:
- Reset clears registers, FIFO, sample counters, alert state, IRQ, and low-power state.
- SAMPLE_PERIOD controls periodic sensor_sample_req generation while CONTROL.ENABLE is set.
- SENSOR_SELECT enables sampling of temperature, humidity, and air-quality channels.
- On sensor_valid, capture enabled sensor channels into latest-value registers and push a packed sample record into a 16-entry FIFO.
- Compare captured readings against threshold registers and latch ALERT_STATUS bits when limits are crossed.
- alert_irq asserts when CONTROL.IRQ_ENABLE is set and any ALERT_STATUS bit is set.
- Firmware can read FIFO_DATA to pop buffered sample records and read FIFO_LEVEL for telemetry.
- FIFO overflow latches an alert bit without corrupting existing unread samples.
- LOW_POWER_EN gates periodic sample requests when no channels are enabled or when sample period is zero, and low_power_active reflects this state.
- SAMPLE_COUNT increments once per completed sample event.

Generate synthesizable SystemVerilog, a register map, assertions, a simulation testbench, UPF-lite collateral, and a packaging manifest.
