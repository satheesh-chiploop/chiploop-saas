Create an FPGA-friendly PWM LED demo for board prototyping.

Top module:
- pwm_fpga_demo

Target behavior:
- Use a single board clock input named clk.
- Drive one LED output named led.
- Generate a visible breathing/fading PWM pattern by combining a slow counter, an 8-bit PWM counter, an 8-bit duty-cycle register, and a direction bit.
- The duty cycle should slowly ramp up and down so the LED visibly changes brightness.
- Keep the RTL synthesizable for Lattice FPGA open-source flows.
- Avoid ASIC-only constructs, delays, real-number types, DPI, memories, vendor primitives, and testbench-only code in the top module.

FPGA constraints:
- Generate board-specific starter pin constraints after the board is selected.
- Use PCF for iCE40 boards and LPF for ECP5 boards.
- The starter constraints are for demo bring-up and must be reviewed before programming physical hardware.

Generate FPGA-ready SystemVerilog/Verilog RTL suitable for lint, Yosys synthesis, nextpnr place-and-route, timing review, and bitstream handoff.
