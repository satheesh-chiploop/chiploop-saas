Design a parameterized PWM controller.

This version is controlled by firmware through a memory-mapped register interface.

Inputs:
- clk
- reset_n
- wr_en
- wr_addr[7:0]
- wr_data[7:0]
- rd_en
- rd_addr[7:0]

Outputs:
- rd_data[7:0]
- pwm_out
- counter_value[7:0]

Register map:
- 0x00 CONTROL: bit 0 ENABLE, read/write
- 0x04 DUTY_CYCLE: duty_cycle[7:0], read/write
- 0x08 PERIOD: period[7:0], read/write
- 0x0C COUNTER_VALUE: counter_value[7:0], read-only status

Behavior:
- All registers and outputs reset to zero when reset_n is low.
- Counter increments every clock while CONTROL.ENABLE is high and PERIOD is nonzero.
- Counter wraps to zero when it reaches PERIOD.
- pwm_out is high while enabled and counter_value is less than duty_cycle[7:0].
- Reads return the addressed register value, including live COUNTER_VALUE status.

Generate synthesizable SystemVerilog, a register map, assertions, a simulation testbench, UPF-lite collateral, and a packaging manifest.
